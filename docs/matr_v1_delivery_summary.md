# MATR-v1 Project Delivery Summary

## What Was Implemented

- Dataset changes: none; the released BCSS loader and 23,422-sample training
  split were reused unchanged.
- Model changes: OT-MTR replaced the CAM28_1 single direction with two centered
  modes per class and a frozen log-mean-exp aggregation; SACR added a
  zero-anchored dynamic sparse correction while preserving original GSR and
  CH15.
- Training engineering changes: added frozen balanced OT, the epoch1–5 OT
  ramp, mechanism logging, and epoch 5/10/15/20/25 checkpoints with epoch25
  FINAL as the only primary checkpoint.
- Inference or evaluation changes: official inference was preserved; an
  isolated same-script A0/MATR validation comparison and standalone CAM28_1
  readout were added.
- Visualization changes: archived training-loss, prototype-dynamics and
  SACR-dynamics figures.
- README and documentation changes: recorded the complete environment, data,
  commands, artifacts, final results and preregistered stop decision.

## Validation Evidence

- Local checks: the frozen implementation commit contains the focused MATR
  unit/protocol tests; no model code was changed during result archival.
- Server-side checks: the real batch20 BF16 preflight passed with correct CAM
  shapes, exact identity controls, finite losses, valid Sinkhorn marginals,
  active OT/offset gradients, complete pretrained backbone loading and no
  segmentation GT in training.
- Training results: fresh BCSS seed42 training completed 25/25 epochs and
  29,275 optimizer steps. Mean epoch time was 355.64 seconds and peak model
  CUDA memory was 4.812 GiB.
- Evaluation results: A0 and MATR epoch25 FINAL were evaluated on all 3,418
  BCSS validation images with the same released metric and inference protocol.
  MATR mIoU/mDice were 66.9280/80.0081 versus A0 67.3283/80.2683.
- Visualization artifacts: `training_losses.png`, `prototype_dynamics.png`
  and `sacr_dynamics.png` were generated from frozen training history.

## Remaining Items

- What still needs to be run: nothing within the frozen MATR-v1 experiment.
- What still needs verification: human review of this result commit and report.
- What is intentionally deferred: BCSS test, LUAD, seeds 11/17, component
  ablations, mode/lambda/epsilon/offset sweeps, diversity loss and MATR-v2.
