# PCSI-v1 reproducibility

This is the BCSS seed-42 Phase0 test of semantic injection **before** CCRA. The full 25-epoch experiment is explicitly out of scope. The implementation branch is `experiment/pcsi-v1`.

## Frozen inputs

- HQMR epoch-25 checkpoint SHA-256: `84dab82140eb79176bef3f518b6508b6167b328b6d55126d24efffa7467e4abb`.
- PLIP: local frozen `vinid-plip` snapshot; prior preparation manifest records the weight hash.
- VPCA/PDSR concept cache: the exact cache generated by the previous PDSR-VPCA Phase0 experiment.
- C0: UMRF's frozen `gt_free_prediction_maps.uint8.npy`, not a newly generated baseline.
- Data: BCSS training 23,422 images, validation 3,418 images. Training uses image-level labels only. Validation masks are opened only after both C1/C2 complete E5.

## Run order

1. `audits/pcsi_v1/trace_forward_graph.py` on the untouched HQMR checkpoint.
2. `audits/pcsi_v1/test_semantic_injection.py` and `audit_gradient_path.py`; Phase C requires `phaseA_forward/phaseA_decision.json` with `PHASE_A_DECISION=GO`.
3. `audits/pcsi_v1/audit_vpca_collapse.py`, using training images and image labels only. VPCA-v1 remains closed.
4. `tools/pcsi_v1/identity.py`, 32 fixed validation images without masks. Both C1/C2 require exact gamma-zero identity.
5. `tools/pcsi_v1/train.py --variant C1 ...` and then `--variant C2 ...`, each exactly five epochs, seed 42, micro-batch 5, accumulation 4, effective batch 20, BF16, original `PolyOptimizer` settings. This script refuses a nonempty result directory other than `process.log`.
6. `tools/pcsi_v1/evaluate.py ...` only after **both** `runtime.json` files say `TRAINING_COMPLETE` and 5,855 optimizer steps. It uses the exact UMRF C0 bank and UMRF frozen component table.

## Output contract

`phaseA_forward/` contains graph, alpha-zero identity, causal sensitivity, and gradient audit. `phaseB_vpca/` contains text geometry, raw response, pooling, temperature, rho, bias, and ISR tables/figures. `phaseC/identity_pretrain.json` is the pretraining gate. `C1_VLM_LAST/` and `C2_STATIC_PDSR/` contain train logs, E5 adapter checkpoint, gradient/runtime manifests, E5 prediction maps, component-level L5 responsibility, and posttraining tensor drift/hashes. `metrics/final_result.json` and the final Markdown report summarize the paired analysis.

Do not use this branch to run Full25. No segmentation GT is used to tune weights, choose checkpoints, or change the Phase0 protocol.
